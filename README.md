# Git Course

A comprehensive Git & GitHub course based on the tutorials of **Elzero Web School**.

## 📚 About the Course

This repository contains notes, examples, and practical exercises for learning Git and GitHub fundamentals, including:

- Git basics
- Repository management
- Branching and merging
- Remote repositories
- GitHub workflows
- Collaboration techniques
- Best practices

## 🎯 Purpose

The main goal of this repository is to document the learning journey and provide a reference for Git and GitHub concepts.
